## 1. Краткое резюме

- **Патч** поверх Maven **1.1.0** (semantic locator pipeline).
- **`frap.runtime.dir`**: бинарь `frap-core-rpc` в `<jar-dir>/.frap/bin/`, не в `/tmp` — для корпоративных MCP/Core.
- **Parity SnapshotBuilder**: live discover отдаёт `computed_role`, `scope_hint`, `visible` (как MCP `snapshot.js`).
- **Без ломающих изменений** Java API; опциональные поля в JSON `DOMElementInfo`.

## 2. Объём и методология

| В релизе 1.1.1 | Вне релиза |
|----------------|------------|
| `FrapRuntimePaths`, каталоги work/logs MCP | WebDriver / Selenide (v1.4.0) |
| Поля коллектора в SnapshotBuilder | iframe discover (F018) |
| Примеры MCP (`<frap.runtime.dir>/work`) | npm discover |
| dom-benchmark + locator-quality (те же пороги) | Gates на live prod URL |

Baseline: **`java-v1.1.0`**. Релиз: **`java-v1.1.1`**. Метрики с фикстур и CI.

## 3. Качество локаторов

**Gate:** `contract_locator_quality` — **10/10 pass** (65 элементов, `snap-person.json`).

| Порог | Значение |
|-------|----------|
| max positional | ≤ 4 |
| min high confidence (≥0.8) | ≥ 55 |
| min semantic strategy | ≥ 55 |

**Инварианты (как в 1.1.0):** валидные имена методов PoG; LIST → relative; дубли текста → scope; PoG с `getBy*` для семантики.

**1.1.1:** ранжирование Core без изменений; улучшение — **богаче live snapshot** (раздел 4).

## 4. Discover и кластеризация

**Gate:** `contract_dom_benchmark` — **9/9 страниц**.

Страницы 01–09: catalog LIST, text/role, дубли, aria, shadow, contenteditable, role=button, generated id, sibling label (паттерн C012/C013).

**CI:** `DomBenchmarkE2eTest`, `DiscoveryPageObjectE2eTest`, `./scripts/run-java-e2e.sh`.

**Дельта 1.1.1:** в Java snapshot появились `computed_role` и `scope_hint` для scoped locators на live-страницах без смены ground-truth.

## 5. Генерация Page Object

- RPC `generate_page_object` — семантика 1.1.0.
- E2E: компилируемый PoG, live resolution relative locators на card-list.
- Стратегии: `getByTestId`, `getByRole`, `getByText`, scoped `getByText` при SCOPE-uniqueness.
