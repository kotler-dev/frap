## 1. Executive summary

- **Patch release** on top of Maven **1.1.0** semantic locator pipeline.
- **`frap.runtime.dir`**: native `frap-core-rpc` extracts under `<jar-dir>/.frap/bin/` instead of `/tmp` — unblocks corporate MCP/Core deploy.
- **SnapshotBuilder parity**: live Playwright discover emits `computed_role`, `scope_hint`, `visible` (same collector signals as MCP `snapshot.js`).
- **No breaking API** in Java DTOs; optional JSON fields on `DOMElementInfo`.

## 2. Scope & methodology

| In scope (1.1.1) | Out of scope |
|------------------|--------------|
| `FrapRuntimePaths`, MCP work/logs defaults | WebDriver / Selenide (v1.4.0) |

| MCP tool doc examples (`<frap.runtime.dir>/work`) | npm discover release |
| dom-benchmark + locator-quality **unchanged thresholds** | Live prod URL gates |

## 5. Page Object generation

## 10. Caveats & non-claims

- Does **not** add Selenium/WebDriver healing.
- Does **not** certify success on arbitrary live sites (C013 is optional, headed, network-dependent).
- Does **not** change dom-benchmark ground-truth files — semantic policy frozen in fixtures.
- MCP FILE-mode still requires the agent to run snapshot JS in the browser; frap has no built-in browser.
